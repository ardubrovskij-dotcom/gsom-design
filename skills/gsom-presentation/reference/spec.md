# Формат spec.json для `gsom_deck.py build`

```json
{
  "lang": "ru",
  "slides": [
    {"use": "<ключ из каталога>", "fields": {"<id>": <значение>, ...}, "add": [...], "notes": "..."}
  ]
}
```

- `lang` — `ru` (по умолчанию) или `en`: в EN логотипы на всех слайдах заменяются на английские.
- `use` — ключ слайда из `reference/catalog.md` (или `blank` / `blank-2`).
- `fields` — что положить в фигуры слайда. Ключ — `id` фигуры из
  `python3 scripts/gsom_deck.py fields <key>` (с `#` или без), либо `"title"` (заголовок слайда),
  либо `"ph<N>"` (плейсхолдер с индексом N).
- `add` — свободные элементы поверх слайда (см. ниже).
- `notes` — заметки докладчика.

Относительные пути к картинкам считаются от папки, где лежит spec.json.

## Значения `fields`

| Фигура (`kind` в `fields`) | Значение | Что произойдёт |
|---|---|---|
| `text` | `"строка"` | Текст с оформлением образца. `\n` — новый абзац; если в образце один абзац с переносами строк (крупные заголовки титулов и разделителей), `\n` — перенос строки, и i-я строка берёт стиль i-й строки образца (так сохраняются двухцветные заголовки `section-photo`). |
| `text` | `["абзац 1", "абзац 2"]` | Абзацы. i-й абзац берёт стиль i-го абзаца образца (например, «заголовок + текст»), лишние — стиль последнего. |
| `text` | `"Рост на **38%**"` | `**…**` — жирный фрагмент. |
| любая | `null` | Удалить фигуру (или целую группу — укажите id группы). |
| `table` | `[["A","B"],["1","2"]]` | Строки таблицы сверху вниз (с шапкой, если она есть в образце). Лишние строки образца удаляются, недостающие копируются с последней. Подложка таблицы подгоняется по высоте. `null` в ячейке — оставить как есть. |
| `table` | `{"rows": [...], "total": true}` | То же, но последняя строка берёт оформление строки «Итого» образца. |
| `chart` | `{"categories": [...], "series": [{"name": "...", "values": [...]}]}` | Новые данные, оформление образца. Опционально `"min"`, `"max"`, `"legend": true`, у ряда `"format": "0%"`. |
| `picture` / `image-fill` | `"photo.jpg"` | Фото вписывается в рамку с обрезкой по центру (без искажений). `{"path": "...", "fit": "stretch"}` — растянуть; `"grayscale": true` — сделать ч/б (онлайн-ДПО, MBA/EMBA). |
| `picture` / `group` (иконка) | `{"from": "lib-icons-finance#30", "color": "white"}` | Взять иконку/иллюстрацию/фото из библиотеки шаблона; `color` — перекрасить (`white` для иконок в красной/серой шапке, `red`, `grey` или HEX). Номера — на `assets/catalog/lib-*.jpg`. |

## Свободные элементы `add`

Координаты — дюймы. Слайд 13,33 × 7,5. **Рабочая область** контентного слайда:
x от 1,2 до 12,15, y от 1,4 до 6,95 (под заголовком, над номером слайда).
Для пустого слайда используйте `"use": "blank"` (только заголовок в стиле шаблона).

| type | Параметры |
|---|---|
| `text` | `x y w h text` (строка или список), `size` (pt, по умолчанию 14), `bold`, `color` (`grey`/`red`/`white`/HEX), `align` (`left`/`center`), `bullets: true` |
| `card` | `x y w h title text`, `accent` (`red`/`grey`), `bullets`, `size`, `title_size`, `head_h` — карточка как в шаблоне (светло-серое тело + цветная шапка) |
| `table` | `x y w h rows`, `size`, `total_row: true` — красная шапка, зебра `#EBEDF0` |
| `chart` | `x y w h chart categories series`, `chart`: `column`, `column-stacked`, `bar`, `bar-stacked`, `line`, `pie`, `doughnut`; `palette` (`general`, `bachelor`, `master`, `phd`, `dpo`, `mba`, `reds`, `greys`), `labels` (по умолчанию true), `format` (напр. `"0%"`), `legend`, `title` |
| `image` | `x y w h path`, `container: true` — фирменный контейнер со срезанными углами, `grayscale: true` — ч/б |

Именованные цвета: `red #C31632`, `grey #4A5761`, `grey2…grey5`, `light #EBEDF0`, `white`, `gold #D4A865`,
`bachelor`, `master`, `phd`, `dpo`, `mba`.

## Пример

```json
{
  "lang": "ru",
  "slides": [
    {"use": "title-slogan-photo", "fields": {
      "title": "Цифровая трансформация ВШМ",
      "29": "Стратегическая сессия", "30": "Октябрь 2026"}},
    {"use": "cards-3", "fields": {
      "title": "Три направления развития",
      "24": "Онлайн-программы", "16": "Корпоративное обучение", "21": "Исследования",
      "44": [["5 новых курсов"], ["Единая LMS"], ["Партнёрства с вузами"], ["Сертификация"]],
      "19": [["Модульные программы"], ["Кастомизация"], ["Наставничество"], ["Оценка эффекта"]],
      "22": [["5", "новых курсов"], ["12", "партнёров"], ["+30%", "выручки"], ["2", "центра"]]}},
    {"use": "blank", "fields": {"title": "Набор по годам"}, "add": [
      {"type": "chart", "chart": "column", "x": 1.2, "y": 1.4, "w": 7.0, "h": 5.4,
       "categories": ["2023", "2024", "2025"], "series": [{"name": "Студенты", "values": [1200, 1350, 1520]}]},
      {"type": "card", "x": 8.6, "y": 1.4, "w": 3.55, "h": 5.4, "title": "Вывод",
       "text": ["Рост +27% за 2 года", "Драйвер — магистратура"], "bullets": true}]}
  ]
}
```

## Использование как библиотеки

```python
import sys; sys.path.insert(0, "<skill>/scripts")
from gsom_deck import Deck
deck = Deck(lang="ru")
s = deck.add("bullets-4", {"title": "Выводы", "5": "…", "8": "…", "11": "…", "14": "…"})
deck.add("blank", {"title": "График"}, add=[{"type": "chart", ...}])
deck.save("out.pptx")
```
`deck.add()` возвращает объект `pptx` слайда — дальше можно править его через python-pptx.
