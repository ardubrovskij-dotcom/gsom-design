# Презентации в стиле ВШМ СПбГУ

Скилл собирает .pptx из **официального шаблона ВШМ** (`assets/template.pptx`, 110 образцовых
слайдов): нужные слайды клонируются и заполняются твоим контентом. Дизайн при этом не
придумывается — он берётся из шаблона, поэтому результат соответствует брендбуку.

Пути ниже — относительно папки этого скилла (`<skill>` = папка, где лежит этот SKILL.md).

## Файлы

| Файл | Зачем |
|---|---|
| `reference/brandbook.md` | Правила бренда: цвета, шрифт, логотип, паттерн, контейнер, фото, тон. **Прочитай перед первой презентацией.** |
| `reference/catalog.md` | Каталог слайдов шаблона: ключ → назначение → превью. |
| `assets/catalog/<key>.jpg` | Превью слайда с синими метками `#id` фигур, которые заполняются. |
| `reference/spec.md` | Формат spec.json: как заполнять текст, таблицы, диаграммы, фото, иконки; свободные элементы. |
| `scripts/gsom_deck.py` | Движок: `list`, `fields`, `build`, `render`, `check`. |
| `assets/logos/`, `assets/elements/`, `assets/fonts/` | Логотипы (RU/EN, все версии), паттерн, контейнеры, шрифт Inter. |

## Подготовка окружения (один раз)

```bash
python3 -c "import pptx, PIL, lxml" 2>/dev/null || pip install python-pptx pillow lxml
which soffice pdftoppm   # для предпросмотра (LibreOffice + poppler); без них сборка работает, рендер — нет
```
Шрифт Inter для рендера `render` ставит сам из `assets/fonts/`.

## Порядок работы

### 1. Понять задачу
Нужно знать: **тему и цель**, **аудиторию**, **язык** (ru/en), примерный **объём**, есть ли
**данные/цифры, фото, спикер**, относится ли презентация к **направлению** (бакалавриат,
магистратура, аспирантура, онлайн-ДПО, MBA/EMBA — влияет на палитру диаграмм и ч/б-фото).
Если пользователь дал тему и материалы — не засыпай вопросами: разумные умолчания —
русский язык, 8–12 слайдов, общая палитра. Спроси только то, без чего нельзя (например, цифры,
которые нельзя выдумать). **Не придумывай факты, цифры, ФИО и даты** — если данных нет,
оставь явную пометку `[уточнить]` и скажи об этом в ответе.

### 2. Составить план (сторилайн)
Типичная структура: титул → (содержание) → разделы (разделитель + 2–4 контентных слайда) →
вывод/ключевая фраза → контакты. **Один слайд — одна мысль.** Для каждого слайда выбери ключ
из `reference/catalog.md` по смыслу:

| Что показать | Ключи |
|---|---|
| Обложка | `title-slogan-photo` (белая, фото справа), `title-photo` / `title-photo-frame` (фото на весь слайд), `title-no-photo` (без фото, со спикером), `title-program-person` (программа) |
| Раздел | `section` (серый), `section-photo` (с фото, 2-цветный заголовок) |
| Спикер | `section-speaker`, `section-speaker-photo` |
| Содержание | `agenda-8`, `agenda-9` |
| 2–4 тезиса | `bullets-4`, `bullets-icons`, `bullets-conclusion` (с выводом) |
| Сравнение 2–4 блоков | `cards-2`, `cards-3`, `cards-4` (+ `-photo`), `cards-4-circle` |
| Ключевые цифры | `highlights-6`, `highlights-8`, `card-highlights-6`, `statement` |
| Процесс / этапы | `process-steps`, `stages-4`, `timeline-snake`, `cycle`, `cycle-arrows` |
| Хронология | `timeline`, `timeline-cards`, `timeline-3`, `gantt`, `gantt-2` |
| Таблица | `table`, `table-years`, `table-conclusion`, `table-card`, `table-checklist` |
| Диаграммы | `charts-2-bar`, `charts-2-card`, `charts-2-card-2`, `pie-card`, `radar`, `bubble-chart` |
| Структура / схема | `scheme-structure`, `scheme-structure-2`, `scheme-bubbles`, `pyramid`, `matrix`, `venn`, `circle-4/6/9`, `values-house` |
| Фото + текст | `photo-text-left`, `photo-text-right`, `list-photo`, `menu-photo`, `photo-full` |
| Продукт / платформа | `mockup-laptop`, `mockup-phone`, `mockup-online-class` |
| Эмоция / акцент | `quote`, `quote-2`, `question`, `question-photo`, `statement-photo` |
| География | `map-russia`, `map-russia-regions`, `map-world` |
| Контакты | `contacts`, `contacts-photo`, `contacts-qr` |
| Не подходит ничего | `blank` + свободные элементы `add` (карточка, таблица, диаграмма, текст, фото в контейнере) |

Посмотри превью выбранных слайдов (`assets/catalog/<key>.jpg`) — так видно, сколько текста
влезает и какая фигура за что отвечает. Не используй один и тот же ключ подряд много раз —
чередуй форматы.

### 3. Узнать поля и написать spec.json
```bash
python3 <skill>/scripts/gsom_deck.py fields cards-3 timeline title-slogan-photo
```
Для каждого слайда заполни **все** текстовые фигуры с образцом (Lorem, «XX», «Название»…)
своим текстом, а ненужные блоки удали значением `null` (лучше удалить целую группу-карточку,
чем оставить пустую). Формат — `reference/spec.md`. Иконки — из `lib-icons-*`
(`{"from": "lib-icons-finance#30", "color": "white"}`), фото — файлы пользователя
или `lib-photos-*`.

**Объём текста** (ориентиры, проверяются рендером):
- заголовок слайда — до ~45 знаков (одна строка), пиши обычным регистром — ПРОПИСНЫЕ делает стиль;
- тезис в `bullets-*` — 1–3 строки (до ~200 знаков);
- ячейка карточки/таблицы — до ~60 знаков; «XX»-ячейка — число до 4 символов (`12`, `+30%`, `5 млн`);
- титул/разделитель — до 3–4 коротких строк.
Текст — деловой, конкретный, с цифрами; без восклицаний и канцелярита. Неразрывные пробелы
после предлогов и союзов движок ставит сам.

### 4. Собрать
```bash
python3 <skill>/scripts/gsom_deck.py build spec.json "Презентация.pptx"
```
Сборщик предупреждает об оставшихся текстах-заглушках шаблона и о фигурах за краем слайда —
**исправь все предупреждения** (заполни или удали фигуру, сократи таблицу) и пересобери.

### 5. Проверить глазами (обязательно)
```bash
python3 <skill>/scripts/gsom_deck.py render "Презентация.pptx" preview/
```
Открой `preview/contact-sheet.png`, затем каждый `preview/slide-*.png`. Ищи: текст вылезает
за плашку или обрезан, наложения, пустые карточки, «висящие» блоки после удаления, слишком
мелкий текст, логотип/номер перекрыт. Исправь spec.json (сократи текст, смени ключ слайда,
удали лишнее) и повтори 4–5, пока всё не станет чисто.

### 6. Сдать результат
Отдай путь к .pptx (и, если просили, превью). Кратко перечисли структуру и всё, что требует
уточнения (`[уточнить]`, фото-заглушки из библиотеки, которые стоит заменить).

## Правила бренда, которые нельзя нарушать
- Только цвета брендбука (`reference/brandbook.md`); основной — красный `#C31632`.
- Только шрифт Inter (в шаблоне уже настроен; в `add` — по умолчанию).
- Логотип уже на мастер-слайде и титулах: не добавлять, не двигать, не ставить на фото.
- Текст — выравнивание влево (центр — только в фразах-акцентах), никогда вправо.
- Для онлайн-ДПО и MBA/EMBA фото — только чёрно-белые (`{"path": "...", "grayscale": true}`).
- Не рисовать свои иконки и не использовать эмодзи — только библиотека `lib-icons-*`.
- Английская версия: `"lang": "en"` — логотипы подставятся английские.

## Если нужно больше, чем каталог
`gsom_deck.py` можно импортировать (`from gsom_deck import Deck`) и после `deck.add(...)`
дорабатывать слайд через python-pptx, соблюдая брендбук: Inter, цвета из `COLORS`/`PALETTES`,
рабочая область x 1,2–12,15″, y 1,4–6,95″.
