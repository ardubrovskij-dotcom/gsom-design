# Презентации в стиле ВШМ: установка и работа

Скилл `gsom-presentation` делает презентации PowerPoint по брендбуку ВШМ СПбГУ. Он собирает
слайды из официального шаблона ВШМ, поэтому фирменные цвета, шрифт Inter, логотип и вёрстка
получаются правильными сами собой. От вас нужны тема и содержание.

---

## 1. Установка

Выберите один из вариантов.

### Вариант А. Claude Code: терминал, десктоп-приложение, VS Code

1. Добавьте каталог и установите плагин. Это можно сделать в терминале:
   ```bash
   claude plugin marketplace add ardubrovskij-dotcom/gsom-design
   claude plugin install gsom-design@gsom-design
   ```
   Или внутри сессии Claude Code: `/plugin marketplace add ardubrovskij-dotcom/gsom-design`,
   затем `/plugin install gsom-design@gsom-design` и подтвердите установку в открывшейся панели.
2. Перезапустите сессию (или выполните `/reload-plugins`).
3. Проверьте: `claude plugin list` должен показать `gsom-design@gsom-design` со статусом `enabled`.
4. Установите зависимости (один раз):
   ```bash
   pip install python-pptx pillow lxml
   ```
   Для визуальной самопроверки слайдов нужны LibreOffice и poppler. Это необязательно,
   но рекомендуется:
   | ОС | Команда |
   |---|---|
   | macOS | `brew install --cask libreoffice && brew install poppler` |
   | Ubuntu/Debian | `sudo apt install libreoffice poppler-utils` |
   | Windows | установщик с libreoffice.org и сборка «poppler for Windows»; папки `LibreOffice\program` и `poppler\bin` добавить в PATH |

### Вариант Б. claude.ai (веб и приложения)

1. Скачайте репозиторий: на странице GitHub нажмите **Code → Download ZIP** и распакуйте.
2. Заархивируйте папку `skills/gsom-presentation` так, чтобы в корне архива лежала папка
   `gsom-presentation`:
   ```bash
   cd skills && zip -r gsom-presentation.zip gsom-presentation
   ```
3. В claude.ai откройте **Customize → Skills → «+» → Create skill → Upload a skill** и загрузите архив.
4. Включите **Code execution and file creation**:
   - на тарифах Free, Pro и Max — в Settings → Capabilities;
   - на Team и Enterprise — это делает владелец организации.

> Ограничения: архив весит около 40 МБ, а лимит загрузки в справке claude.ai не указан.
> В веб-среде может не оказаться LibreOffice, тогда Claude соберёт файл, но не сможет
> посмотреть превью слайдов. Если загрузка не проходит, используйте вариант А.

## 2. Как работать

### Попросите
Напишите в чате: **«Создай презентацию в стиле ВШМ»** + тема. Чем больше контекста, тем лучше
результат:

- **о чём и зачем:** тема, цель, ключевая мысль;
- **для кого:** абитуриенты, партнёры, учёный совет, студенты…;
- **объём:** например, «10 слайдов» (по умолчанию 8–12);
- **материалы:** цифры, таблицы, текст, фото, старая презентация — приложите файлы;
- **язык:** по умолчанию русский; для английского напишите «на английском»;
- **направление**, если есть: бакалавриат, магистратура, аспирантура, онлайн-ДПО, MBA/EMBA.

Примеры запросов:
- «Создай презентацию в стиле ВШМ: итоги приёмной кампании 2026. Данные в таблице во вложении, 10 слайдов, для учёного совета».
- «Переоформи эту презентацию в фирменный стиль ВШМ» (с приложенным .pptx или текстом).
- «Make a GSOM-style deck in English about our Executive MBA partnership, 8 slides».

Если скилл не подхватился сам, вызовите его явно: в Claude Code —
`/gsom-design:gsom-presentation`, в claude.ai — упомяните «скилл gsom-presentation».

### Что делает Claude
1. Уточняет то, без чего нельзя (например, цифры — **он их не выдумывает**; пропуски помечает
   `[уточнить]`).
2. Составляет план и подбирает подходящие слайды из шаблона: титул, разделители, карточки,
   таблицы, диаграммы, таймлайны, цитаты, контакты.
3. Заполняет слайды вашим текстом, данными, фото и фирменными иконками.
4. Рендерит превью, сам проверяет слайды и исправляет наложения и лишний текст.
5. Отдаёт готовый `.pptx`: в Claude Code — файл в папке проекта, в claude.ai — ссылку на скачивание.

### Правьте словами
- «Сократи текст на слайде 4 до трёх тезисов».
- «Слайд 6 сделай таблицей, а не карточками».
- «Замени фото на титуле на это» + приложенная картинка.
- «Добавь слайд с диаграммой динамики набора по годам».
- «Сделай английскую версию».

## 3. Полезно знать

- **Шрифт Inter.** Чтобы презентация выглядела правильно на вашем компьютере, установите Inter:
  он лежит в `skills/gsom-presentation/assets/fonts/` или доступен на fonts.google.com.
  Без него PowerPoint подставит другой шрифт.
- **Фото.** Если своих фото нет, Claude возьмёт фото кампуса и студентов из шаблона ВШМ.
  Для внешних материалов лучше приложить свои.
- **Онлайн-ДПО и MBA/EMBA.** По брендбуку фото для этих направлений только чёрно-белые,
  Claude сделает их ч/б сам.
- **Готовые слайды с фактами о ВШМ** (рейтинги, «факты о школе») взяты из шаблона 2024 года.
  Перед использованием проверьте актуальность цифр.
- **Брендбук.** Правила, по которым работает скилл: `skills/gsom-presentation/reference/brandbook.md`.
  Вопросы по фирменному стилю — GSOMmarketing@gsom.spbu.ru.

## 4. Обновление и удаление

```bash
claude plugin marketplace update gsom-design      # получить свежую версию каталога
claude plugin update gsom-design@gsom-design      # обновить плагин
claude plugin uninstall gsom-design@gsom-design   # удалить
```
В claude.ai: удалите старый скилл в Customize → Skills и загрузите новый архив.

## 5. Если что-то не работает

| Симптом | Что сделать |
|---|---|
| Claude делает презентацию не в стиле ВШМ | Вызовите скилл явно (см. раздел 2); проверьте `claude plugin list` |
| Ошибка `No module named 'pptx'` | `pip install python-pptx pillow lxml` |
| Claude пишет, что не может сделать превью | Установите LibreOffice и poppler (раздел 1); файл при этом всё равно собирается |
| В PowerPoint «не тот» шрифт | Установите Inter (раздел 3) |
| claude.ai не принимает архив | Проверьте, что в корне архива папка `gsom-presentation`; если не помогает — вариант А |
